# Той шақыру — клон шаблона Naz «Heritage»

Vue 3 + Vite. Точная копия шаблона heritage с shakyrtu.kz: узкая колонка-открытка,
акварельные фоны с қазақ орнаментами, каллиграфия, видео пары в национальных
костюмах на hero. Структура прежняя — всё правится в `src/config/invitation.config.js`.

## Секции (как на скринах)
1. **Hero** — видео (heritage-hero.mp4), «Сіздерді тойымызға шақырамыз», имена
   в столбик, дата в разрядку. Круглая кнопка музыки внизу слева.
2. **Құрметті қонақтар!** — текст приглашения, «1 Қазан 2026», календарь
   (каллиграфические цифры, сердечко на дате), «Сағат 18:00».
3. **Мекен-жай** — Той орны, город, адрес, зал.
4. **Бағдарлама** — таймлайн: line-art иконки | сердечки на линии | время каллиграфией.
5. **Тойға дейін:** — отсчёт каллиграфическими цифрами + «Тойға келуіңізді растауыңызды сұраймыз!».
6. **Той иелері** — имена родителей + «Сіздерді тойымызда күтеміз!».
7. **Анкета** — имя (округлое поле), радио «Иә, әрине / Жұбайыммен келемін / Келе алмаймын», «Жіберу».
8. **Тілектер** — тёмная кнопка «✉ Тілек қалдыру», раскрывает форму пожелания.

Языки: /kk /ru /en. Анкета и пожелания уходят в Google Sheets (лист «Тілектер»
для пожеланий) + Telegram — `.env`: VITE_SHEETS_URL, VITE_TG_TOKEN, VITE_TG_CHAT_ID.
`google-apps-script/Code.gs` вставить в Apps Script заново и переопубликовать.

## Запуск
```bash
npm install
npm run dev
npm run build
```

## Важно про внешние файлы
Видео, постер и шрифт «Asylbek Shelley» сейчас грузятся напрямую с shakyrtu.kz:
- https://shakyrtu.kz/media/a/heritage-hero.mp4
- https://shakyrtu.kz/media/a/heritage-hero-poster.webp
- https://shakyrtu.kz/fonts/AsylbekM02Shelley.woff2 (@font-face в `src/style.css`)

Это чужой сервер — файлы могут закрыть в любой момент. Надёжнее скачать их в
`public/media/` и `public/fonts/` и поменять пути в конфиге и style.css.
Если шрифт недоступен, каллиграфия откатится на Cormorant Garamond Italic.

Фоны секций (heritage-1/2/3.webp) и иконки программы лежат локально в
`src/assets/images/naz/`.

Неиспользуемые старые блоки (DressCodeBlock, FinalThanksBlock) оставлены в
`src/components/` — можно вернуть в App.vue при желании.
